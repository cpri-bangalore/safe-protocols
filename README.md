# Safe protocols for Critical infrastructure

SafeASN, SafeGOOSE, SafeSV, SafeMMS, and SafeDNP3

## About

These are safe-subset protocol filters for ASN, GOOSE, SV, MMS, and DNP3.

Like `MISRA-C for C` and `JSF++ for C++`

This work includes 10 CVEs on IEC-104 and IEC-61850:

1. https://www.cisa.gov/news-events/ics-advisories/icsa-26-211-10
2. https://www.cisa.gov/news-events/ics-advisories/icsa-26-211-11
